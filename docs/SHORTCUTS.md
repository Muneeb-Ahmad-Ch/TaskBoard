# Keyboard shortcuts

Shortcuts don't fire while you're typing in a text field (except where noted).

## Anywhere in Windows

| Keys | Action |
|---|---|
| Ctrl+Shift+Space | Bring Taskboard forward with Quick Add focused |

## Everywhere in the app

| Keys | Action |
|---|---|
| Ctrl+K | Command palette: jump to sections/groups/projects, search tasks, run any action (works while typing) |
| N | Focus Quick Add |
| ? | Show all keyboard shortcuts |
| / or Ctrl+F | Filter tasks |
| 1 / 2 / 3 | The visible view tabs, left to right (Table / Board / Calendar by default) |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Esc | Close the open dialog, menu or task panel; on a subtask, go back to its parent first |

## Quick Add syntax

| Type | Means |
|---|---|
| `#design` | tag |
| `!high`, `!urgent`, `!low`, `!1`–`!4`, `!!`, `!!!` | priority |
| `@website`, `@"Website redesign"`, `@"Acme/Website"` | project (fuzzy) |
| `today`, `tomorrow`, `fri`, `next mon`, `in 3 days`, `oct 20`, `2026-10-20` | due date |
| `3pm`, `at 9:30`, `15:00`, `noon` | due time |
| `3-4pm` | time range |
| `~30m`, `~2h`, `~1h30m` | estimate |
| `every day`, `every weekday`, `every mon and thu`, `every 2 weeks`, `every month` | repeat on a schedule |
| `every! 3 days`, `every! month` | repeat after completion |
| `"quoted words"` | keep literally in the title |

## Table

| Keys | Action |
|---|---|
| ↑ ↓ or J / K | Move the selection (Shift extends it) |
| Enter | Open the task panel |
| F2 or E | Rename |
| Space | Mark selected tasks done / not done |
| Delete | Delete selected tasks (undoable) |
| Ctrl+A | Select all loaded rows |
| Esc | Clear selection |
| ← / → on a column's resize handle | Make the column narrower / wider (double-click the handle to reset) |

## Board

| Keys | Action |
|---|---|
| Tab | Focus a card |
| Enter | Open the task |
| Space | Pick up the card; ← → change column, ↑ ↓ change position; Space drops, Esc cancels |

## Sidebar

| Keys | Action |
|---|---|
| Alt+↑ / Alt+↓ | Move the focused section, group or project up / down (also in its right-click menu) |
| Right-click | Section / group / project / saved view actions (edit, rename, move, delete); on Today, Inbox…: Customize sidebar (Settings → Layout) |
| Double-click | Rename a section, group or project |

## Calendar

| Keys | Action |
|---|---|
| ← / → | Previous / next period |
| T | Today |
| M / W / D / A | Month / Week / Day / Agenda |
| Alt + drag on the grid | Create a time block instead of a meeting |
